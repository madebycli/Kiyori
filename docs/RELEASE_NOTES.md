# Kiyori release notes

## Unreleased integrated rebuild candidate

This candidate introduces the Kiyori Android identity while retaining AniList sign-in and API compatibility.

- Configure two to five main destinations and keep Home as the safe fallback.
- Add Calendar, current-list, chart, and semantic current/next-season shortcuts to the main navigation.
- Browse a timezone-safe Calendar from today through the next fourteen days. The Monday–Sunday header
  shows exact filtered day counts, supports touch, swipe and accessible controls, and preserves list/grid choice.
- Open notifications, settings and the signed-in account directly from Home.
- Keep credential-bearing preferences out of Android cloud backup and device transfer.

## Before publishing

Run the complete validation matrix, verify signed release artifacts, and complete device acceptance.
Select final version metadata and a release tag only after those checks pass.
