# Kiyori brand mark

`kiyori-mark.svg` is the canonical editable source for the phone launcher mark and its 512×512 preview. It is an original abstract **K** built from narrow, ribbon-like strokes over layered navy fields with one restrained violet accent.

The mark intentionally contains no text, island imagery, white plate, or halo. The app module contains the adaptive foreground/background, legacy fallback, monochrome themed variant, and transparent splash mark derived from this source. It is phone-scoped so the upstream Wear resources remain unchanged.
